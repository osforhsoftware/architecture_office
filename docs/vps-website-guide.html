VPS manual guide

VPS-ൽ website എത്ര ഉണ്ട്, പുതിയത് എങ്ങനെ add ചെയ്യാം

2. VPS-ൽ ഇപ്പോൾ എത്ര site ഉണ്ട് — അത് കാണാൻ

SSH കയറി ഈ commands. Output-ലെ ഒരു file = ഒരു Nginx site (ചിലത് default ആകാം).

ls /etc/nginx/sites-enabled
ls /var/www
pm2 list
ss -tlnp | grep -E 'nginx|node|php'

Nginx enabled list = visitor-ന് തുറന്നിരിക്കുന്ന hostnames. /var/www = files. pm2 list = Node/Next apps.

ഒരു site-ന്റെ domain കാണാൻ:

grep -R "server_name" /etc/nginx/sites-enabled

3. ഒരു VPS-ൽ പല websites — simple idea

  1. Visitor browser-ൽ address type ചെയ്യുന്നു — domain അല്ലെങ്കിൽ VPS IP.
  2. DNS ആ address-നെ VPS IP-ലേക്ക് കൊണ്ടുപോകുന്നു.
  3. Nginx port 80/443-ൽ കേൾക്കുന്നു. server_name നോക്കി ഏത് site എന്ന് തീരുമാനിക്കുന്നു.
  4. Static / WordPress: files folder-ൽ നിന്ന് അയക്കും.
  5. Next.js / Node: Nginx അകത്തുള്ള port-ലേക്ക് (3001, 3011, …) proxy ചെയ്യും. App PM2 run ചെയ്യണം.
ഒരു site-ന് 4 കാര്യം വേണം
  1. Files — /var/www/your_site
  2. Run method — static = Nginx മാത്രം. Next.js = PM2 + port. WordPress = PHP + MySQL.
  3. Nginx config — sites-available → sites-enabled
  4. Address — domain A record, അല്ലെങ്കിൽ IP മാത്രം test-ന്

4. Domain, subdomain, VPS IP — എങ്ങനെ connect ചെയ്യാം

ആദ്യം VPS-ന്റെ public IP എടുക്കുക (dashboard-ൽ കാണാം, അല്ലെങ്കിൽ SSH-ൽ):

curl -4 ifconfig.me

A) VPS IP മാത്രം (test)

Browser-ൽ http://YOUR_VPS_IP. Nginx-ൽ default site ആണ് കാണുക. പല sites ഉണ്ടെങ്കിൽ IP മാത്രം കൊണ്ട് ശരിയായ site തിരഞ്ഞെടുക്കാൻ ബുദ്ധിമുട്ടാണ്. Production-ന് domain വേണം.

B) Main domain (example: musthakahammed.com)

musthakahammed.com ഇപ്പോൾ Hostinger WordPress ആണ്. Apex DNS VPS-ലേക്ക് മാറ്റിയാൽ WordPress public-ൽ പോകും. Main domain VPS-ലേക്ക് മാറ്റുന്നത് മനസ്സിലായിട്ട് മാത്രം.

C) Subdomain (safe way — പുതിയ site-ന് ഇത് നല്ലത്)

Main domain Hostinger-ൽ നിർത്താം. പുതിയ app-ന് subdomain:

ഉദാഹരണംDNSVPS-ൽ
office-crm.mooo.com A → VPS IP Nginx server_name office-crm.mooo.com + PM2 3011
acmm.mooo.com A → VPS IP ArchOffice. Reuse ചെയ്യരുത് പുതിയ app-ന്
app.musthakahammed.com Cloudflare Tunnel CNAME (local PC) VPS അല്ല
പുതിയത്: blog.yourdomain.com A record Name=blog Value=VPS IP പുതിയ folder + പുതിയ Nginx file

Cloudflare / Hostinger DNS-ൽ:

  1. DNS → Add record
  2. Type: A
  3. Name: blog (subdomain) അല്ലെങ്കിൽ @ (main)
  4. IPv4: VPS IP
  5. Save. 2–30 മിനിറ്റ് wait. Check: ping blog.yourdomain.com

Nginx-ൽ ആ hostname എഴുതണം. DNS മാത്രം മതിയാവില്ല.

6. Next.js / Node.js backend — manual add (AI ഇല്ലാതെ)

Office CRM ഇങ്ങനെയാണ് VPS-ൽ വെച്ചത്. പുതിയ Next.js-ഉം same pattern. WordPress ഇവിടെ വേണ്ട.

6.1 Files

sudo mkdir -p /var/www/mysite
sudo chown -R $USER:$USER /var/www/mysite
cd /var/www/mysite
git clone https://github.com/YOU/YOUR_REPO.git .

Git ഇല്ലെങ്കിൽ laptop-ൽ zip ചെയ്ത് scp കൊണ്ട് copy ചെയ്യാം.

6.2 .env

ഈ app-ന് own database. ArchOffice DB / office_crm DB reuse ചെയ്യരുത്.

mysql -u root -p
CREATE DATABASE mysite CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'mysite'@'localhost' IDENTIFIED BY 'STRONG_PASSWORD';
GRANT ALL PRIVILEGES ON mysite.* TO 'mysite'@'localhost';
FLUSH PRIVILEGES;
EXIT;

/var/www/mysite/.env — FRONTEND_URL=https://mysite.yourdomain.com, own MySQL user, COOKIE_SECURE=true.

6.3 Build + PM2

cd /var/www/mysite
npm ci
npm run build
# tables വേണമെങ്കിൽ ഈ project-ൽ: npm run db:setup  (ഒരിക്കൽ മാത്രം, പുതിയ DB-യിൽ)

PORT=3012 HOSTNAME=127.0.0.1 pm2 start ./node_modules/next/dist/bin/next \
  --name mysite -- start
pm2 save
pm2 startup

Express API ആണെങ്കിൽ: pm2 start server.js --name mysite. App 127.0.0.1-ൽ മാത്രം listen ചെയ്യുക. Public-ലേക്ക് Nginx മാത്രം.

6.4 Nginx reverse proxy

File: /etc/nginx/sites-available/mysite

server {
    listen 80;
    listen [::]:80;
    server_name mysite.yourdomain.com;

    client_max_body_size 32m;

    location / {
        proxy_pass http://127.0.0.1:3012;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}
sudo ln -sfn /etc/nginx/sites-available/mysite /etc/nginx/sites-enabled/mysite
sudo nginx -t
sudo systemctl reload nginx

Office CRM-ന്റെ ready file: project-ൽ deploy/office_crm.nginx.conf. Copy ചെയ്ത് server_name ഉം port ഉം മാറ്റുക. architecture_office Nginx file overwrite ചെയ്യരുത്.

6.5 Update later

cd /var/www/mysite
git pull
npm ci
npm run build
pm2 restart mysite

7. Static website (HTML / CSS / JS only)

Node വേണ്ട. Files Nginx നേരെ serve ചെയ്യും.

sudo mkdir -p /var/www/mysite
sudo chown -R $USER:$USER /var/www/mysite
# index.html ഇവിടെ വെക്കുക

Nginx:

server {
    listen 80;
    listen [::]:80;
    server_name static.yourdomain.com;

    root /var/www/mysite;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
sudo ln -sfn /etc/nginx/sites-available/mysite /etc/nginx/sites-enabled/mysite
sudo nginx -t
sudo systemctl reload nginx

Phone-ൽ നന്നായി കാണണമെങ്കിൽ HTML-ൽ ഇത് വേണം:

<meta name="viewport" content="width=device-width, initial-scale=1" />

8. WordPress VPS-ൽ വേണമെങ്കിൽ

Main musthakahammed.com ഇപ്പോൾ Hostinger-ൽ ആണ്. അത് നിലനിർത്താൻ WordPress subdomain-ൽ വെക്കുക, ഉദാ. wp.yourdomain.com. PHP + MySQL വേണം. Next.js-മായി ഒരേ folder ഉപയോഗിക്കരുത്.

sudo apt update
sudo apt install nginx mysql-server php-fpm php-mysql php-xml php-mbstring php-curl unzip -y

DB (പേര് മാറ്റുക):

mysql -u root -p
CREATE DATABASE wp_mysite CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'wp_mysite'@'localhost' IDENTIFIED BY 'STRONG_PASSWORD';
GRANT ALL ON wp_mysite.* TO 'wp_mysite'@'localhost';
FLUSH PRIVILEGES;
EXIT;
cd /tmp
wget https://wordpress.org/latest.tar.gz
tar -xzf latest.tar.gz
sudo mkdir -p /var/www/wp_mysite
sudo rsync -a wordpress/ /var/www/wp_mysite/
sudo chown -R www-data:www-data /var/www/wp_mysite

Nginx PHP example (PHP version number server-ൽ നോക്കുക: ls /run/php):

server {
    listen 80;
    server_name wp.yourdomain.com;
    root /var/www/wp_mysite;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php-fpm.sock;
    }
}

Browser-ൽ domain തുറന്ന് WordPress installer. DB name / user / password കൊടുക്കുക. SSL ശേഷം Admin → Settings → Site URL HTTPS ആക്കുക.

Hostinger WordPress files VPS copy ചെയ്യാതെ DNS മാത്രം മാറ്റിയാൽ പഴയ site കാണില്ല. Full move = files + database export/import. അത് പ്രത്യേക migration ആണ്.

9. HTTPS (Let’s Encrypt)

DNS A record ഈ VPS-ലേക്ക് വന്നതിന് ശേഷം:

sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d mysite.yourdomain.com

Email, agree. Nginx-ൽ 443 automatically വരും. Fail ആയാൽ: domain IP തെറ്റ്, Cloudflare orange proxy, അല്ലെങ്കിൽ port 80 block.

10. ഒരു പുതിയ site — copy-paste checklist

  1. Name, folder, domain (subdomain നല്ലത്), type (Next / static / WordPress), port (Next മാത്രം).
  2. DNS A → VPS IP. Ping കൊണ്ട് verify.
  3. /var/www/... files. Own DB ആണെങ്കിൽ create.
  4. Next: npm ci, build, PM2. Static: index.html. WP: PHP + installer.
  5. New file in sites-available, symlink sites-enabled.
  6. nginx -t പിന്നെ reload. മറ്റ് site files തൊടരുത്.
  7. certbot --nginx -d your.domain
  8. Browser-ൽ HTTPS തുറക്കുക. ArchOffice / office_crm ഇപ്പോഴും ജോലി ചെയ്യുന്നോ check.

12. സാധാരണ തെറ്റുകൾ

കാണുന്നത്കാരണംചെയ്യേണ്ടത്
Wrong website / default Nginx page server_name match ആകുന്നില്ല, DNS വേറെ IP DNS A check. Nginx hostname exact match. nginx -T | grep server_name
502 Bad Gateway PM2 app down, തെറ്റായ port pm2 list, pm2 logs mysite. proxy_pass port = app port
Certbot failed Domain ഈ VPS-ലേക്ക് വരുന്നില്ല A record, wait DNS, port 80 open
WordPress / CRM മാറിപ്പോയി ഒരേ domain രണ്ട് ഇടത്തേക്ക് ഒരു hostname = ഒരു origin. Subdomain ഉപയോഗിക്കുക
Login cookie / redirect തെറ്റ് FRONTEND_URL പഴയ domain .env-ൽ ശരിയായ HTTPS URL, PM2 restart
Old site broke after new site തെറ്റായ Nginx file overwrite, same port Own vhost file only. pm2 list-ൽ architecture_office / office_crm online ആണോ നോക്കുക
