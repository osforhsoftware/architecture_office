Office CRM കണക്ഷൻ ഗൈഡ്

ലോക്കൽ സൈറ്റ്, MySQL, Cloudflare Tunnel, പബ്ലിക് ഡൊമെയ്ൻ. ഏത് പ്രോഗ്രാം, ഏത് ഘട്ടം, എങ്ങനെ തുടങ്ങാം, എങ്ങനെ നിർത്താം.

ഉപയോഗിക്കുന്ന പ്രോഗ്രാമുകൾ

പ്രോഗ്രാംഎന്തിന്എവിടെ
Node.js, npm Office CRM (Next.js) പ്രവർത്തിപ്പിക്കാൻ പ്രോജക്റ്റ് ഫോൾഡർ
Next.js വെബ്‌സൈറ്റ്. പോർട്ട് 3000 മാത്രം npm run dev
MySQL ലോഗിൻ, ക്ലയന്റുകൾ, പ്രോജക്റ്റുകൾ localhost:3306 മാത്രം. പുറത്തേക്ക് തുറക്കരുത്
PowerShell കമാൻഡുകൾ ഓടിക്കാൻ Windows Terminal
cloudflared ഈ കമ്പ്യൂട്ടറിലെ സൈറ്റ് ഇന്റർനെറ്റിലേക്ക് കൊണ്ടുപോകാൻ C:\Users\USER\AppData\Local\cloudflared\cloudflared.exe
Cloudflare ഡൊമെയ്ൻ DNS, HTTPS dash.cloudflare.com
WordPress (Hostinger) യഥാർത്ഥ പബ്ലിക് സൈറ്റ്. ഫയലുകൾ അവിടെ തന്നെ നിൽക്കും Hostinger. DNS മാറ്റം താൽക്കാലികം മാത്രം

എന്താണ് ബന്ധിപ്പിച്ചിരിക്കുന്നത്

  1. ബ്രൗസർ http://localhost:3000/login തുറക്കുന്നു.
  2. Next.js ആപ്പ് പോർട്ട് 3000-ൽ മറുപടി നൽകുന്നു.
  3. ലോഗിൻ MySQL-നോട് (localhost:3306, ഡാറ്റാബേസ് acmmo_arch) ചോദിക്കുന്നു.
  4. പബ്ലിക് ഡൊമെയ്ൻ വേണമെങ്കിൽ മാത്രം cloudflared പോർട്ട് 3000 Cloudflare-ലേക്ക് അയക്കുന്നു.
  5. MySQL പോർട്ട് ടണലിൽ ഇല്ല. അത് ഈ കമ്പ്യൂട്ടറിനുള്ളിൽ മാത്രം.
ലോക്കൽ ലോഗിൻ വിലാസം

http://localhost:3000/login

.env ഫയലിൽ FRONTEND_URL=http://localhost:3000 ആയിരിക്കണം. ലോക്കലായി ലോഗിൻ ചെയ്യുമ്പോൾ ഈ വിലാസം ഉപയോഗിക്കുക.

1. ലോക്കൽ സൈറ്റ് തുടങ്ങുക

1

പ്രോഗ്രാം: Node.js, npm

പ്രോജക്റ്റ് ഫോൾഡറിൽ PowerShell തുറക്കുക.

cd C:\Users\USER\Documents\shabeeb\architecture_office
npm install
npm run dev

തയ്യാറായാൽ ബ്രൗസറിൽ തുറക്കുക: http://localhost:3000/login

നിർത്താൻ ആ ടെർമിനലിൽ Ctrl+C.

2. ഡാറ്റാബേസ്

2

പ്രോഗ്രാം: MySQL

.env ഫയലിലെ കണക്ഷൻ ഇതാണ്. പാസ്‌വേഡ് ഈ ഡോക്യുമെന്റിൽ എഴുതരുത്.

MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DATABASE=acmmo_arch
Database is unavailable. Please try again. ഈ സന്ദേശം ലോഗിനിൽ മാത്രം വരും. MySQL localhost:3306-ൽ പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ ആപ്പിന് യൂസർ പരിശോധിക്കാൻ കഴിയില്ല. ഈ കമ്പ്യൂട്ടറിൽ MySQL സർവീസ് ഇപ്പോൾ ഓണല്ല. MySQL സ്റ്റാർട്ട് ചെയ്ത ശേഷം ലോഗിൻ വീണ്ടും ശ്രമിക്കുക.

3. Cloudflare Tunnel — ഒരിക്കൽ മാത്രം

3

പ്രോഗ്രാം: cloudflared, Cloudflare ഡാഷ്‌ബോർഡ്

ഇത് ഇതിനകം ഈ കമ്പ്യൂട്ടറിൽ ചെയ്തിട്ടുണ്ട്. പുതിയ കമ്പ്യൂട്ടറിലാണെങ്കിൽ ഈ ക്രമം പിന്തുടരുക.

winget install --id Cloudflare.cloudflared --source winget
cloudflared tunnel login
cloudflared tunnel create architecture-office
cloudflared tunnel route dns architecture-office app.musthakahammed.com

tunnel login ബ്രൗസർ തുറക്കും. musthakahammed.com സോൺ തിരഞ്ഞെടുത്ത് Authorize അമർത്തുക. സർട്ടിഫിക്കറ്റ് ഇവിടെ സേവ് ആകും:

C:\Users\USER\.cloudflared\cert.pem

ടണൽ കീ ഇവിടെയാണ്. ഈ ഫയൽ ആരുമായും പങ്കിടരുത്, git-ൽ ഇടരുത്:

C:\Users\USER\.cloudflared\<tunnel-uuid>.json

കോൺഫിഗ് ഫയൽ: cloudflared\config.yml. അതിൽ പോർട്ട് 3000 മാത്രമേ ഉള്ളൂ. അവസാന നിയമം മറ്റെല്ലാം 404 ആക്കും. warp-routing ഓഫ് ആണ്.

4. പബ്ലിക് ഡൊമെയ്ൻ താൽക്കാലികമായി ലോക്കൽ സൈറ്റിലേക്ക്

4

പ്രോഗ്രാം: Cloudflare DNS + cloudflared

https://musthakahammed.com/ സാധാരണ WordPress സൈറ്റാണ്. താൽക്കാലികമായി ഈ കമ്പ്യൂട്ടറിലെ Office CRM കാണിക്കാൻ apex DNS ടണലിലേക്ക് മാറ്റി. WordPress ഫയലുകൾ Hostinger-ൽ നിലനിൽക്കും.

ടണൽ കോൺഫിഗിൽ ഈ ഹോസ്റ്റുകൾ പോർട്ട് 3000-ലേക്ക് പോകുന്നു:

  • musthakahammed.com
  • www.musthakahammed.com
  • app.musthakahammed.com

crm.musthakahammed.com മാറ്റിയിട്ടില്ല.

ഈ മോഡ് പ്രവർത്തിക്കണമെങ്കിൽ മൂന്നും ഓണായിരിക്കണം: കമ്പ്യൂട്ടർ, npm run dev, ടണൽ.

5. ടണൽ തുടങ്ങുക

5

ആദ്യം ആപ്പ്. പിന്നെ ടണൽ. രണ്ട് ടെർമിനൽ.

npm run dev
npm run tunnel:start

പശ്ചാത്തലത്തിൽ വേണമെങ്കിൽ:

npm run tunnel:start:bg

ലോഗ്: cloudflared\tunnel.log ഉം cloudflared\tunnel.err.log ഉം.

6. ടണൽ നിർത്തുക

6

മുന്നിൽ തുറന്ന ടണൽ ആണെങ്കിൽ ആ വിൻഡോയിൽ Ctrl+C. അത് ടണൽ മാത്രം നിർത്തും. Next.js നിർത്തില്ല.

പശ്ചാത്തല ടണൽ ആണെങ്കിൽ:

npm run tunnel:stop

7. WordPress തിരികെ കൊണ്ടുവരിക

7

പ്രോഗ്രാം: PowerShell, Cloudflare API

പബ്ലിക് ഡൊമെയ്ൻ വീണ്ടും Hostinger WordPress ആക്കാൻ:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/restore-wordpress-dns.ps1
npm run tunnel:stop

ഇത് apex A, AAAA റെക്കോർഡുകൾ പഴയ Hostinger വിലാസത്തിലേക്ക് തിരികെ വെക്കും. ടണൽ നിർത്തിയാൽ app.musthakahammed.com ലോഡ് ആകില്ല. അത് സാധാരണമാണ്.

സാധാരണ പിശകുകൾ

കാണുന്നത്കാരണംചെയ്യേണ്ടത്
Database is unavailable MySQL ഓഫ് ആണ് MySQL സ്റ്റാർട്ട് ചെയ്ത് localhost ലോഗിൻ വീണ്ടും തുറക്കുക
Cloudflare 530, app സൈറ്റ് തുറക്കുന്നില്ല ടണൽ ഓഫ് ആണ് npm run dev ശേഷം npm run tunnel:start
പബ്ലിക് സൈറ്റ് WordPress അല്ല DNS താൽക്കാലികമായി ടണലിലാണ് മുകളിലെ restore കമാൻഡ്
ലോഗിൻ localhost-ന് പകരം ഡൊമെയ്നിലേക്ക് പോകുന്നു FRONTEND_URL പബ്ലിക് ആണ് FRONTEND_URL=http://localhost:3000 ആക്കി ആപ്പ് വീണ്ടും തുടങ്ങുക
VPS-ൽ site add ചെയ്യാൻ

ഈ ഗൈഡ് local PC + tunnel ആണ്. Server-ൽ Next.js / static / WordPress എങ്ങനെ വെക്കാം: VPS website guide.

ചെയ്യരുത്

  • MySQL പോർട്ട് 3306 ടണൽ കോൺഫിഗിൽ ചേർക്കരുത്.
  • .env, cert.pem, ടണൽ JSON ഫയൽ പങ്കിടരുത്.
  • WordPress സൈറ്റ് സ്ഥിരമായി മാറ്റണമെങ്കിൽ ഈ താൽക്കാലിക DNS മാറ്റം മതിയാകില്ല. Hostinger-ൽ ആപ്പ് പ്രത്യേകം ഹോസ്റ്റ് ചെയ്യണം.
